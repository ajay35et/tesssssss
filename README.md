# Rickshaw Music Website

GitHub/Vercel ready static website.

Root files:
- index.html
- style.css
- app.js
- music-config.js

Only one folder:
- images/

Put all your JPG/PNG/WebP/SVG backgrounds inside `images/`.

Then edit `music-config.js` and add the image filenames and YouTube playlist IDs.

Example:
```js
backgrounds: [
  "images/bg-01.jpg",
  "images/bg-02.jpg",
  "images/my-rickshaw-photo.jpg"
]
```

You can add unlimited images to the `images` folder.
